# Secret handling

This public repository documents the application's configuration shape, but it does not contain live credentials. Keep secret values in access-controlled deployment settings. Do not commit them, paste them into issues or logs, or store them in public example files.

If a credential may have been exposed, notify the repository owner through a private channel. The authorized operator should rotate or revoke it with the provider, check affected integrations, and follow the private incident process. Rotation steps, privileged scopes, and operational verification details belong in access-controlled documentation.

Public configuration examples are not evidence that a live deployment is configured or secure. Review the deployed environment separately before processing confidential case material.
